## Дополнение: проекты и контроллеры

Материалы владельца `D:/work/iot.leo4.ru/platerra.ru` изучены только для чтения:
README, восстановленные тексты и метаданные проектов/портфолио. Архив не изменялся.

описания одного проекта не считаются отдельными проектами.

`project-sources.json` связывает записи с исходными заголовками, URL и локальными
файлами архива. Если восстановился только заголовок, публичное описание ограничено
его предметом. Числа масштаба, текущая активность и сроки внедрений не утверждаются.

Контроллеры:

- SipLite: https://siplite.ru/ — SIP 2.0, ESP32 + STM32, Ethernet, NFC и RS-485.
- L4-HMI: репозиторий владельца изучен через авторизованный GitHub API,
  `docs/L4-HMI-CONCEPTUAL-AGENT-ONBOARDING.md`. Статус этого документа —
  concept / architectural draft. На сайте используется формулировка «развиваем

  Репозиторий приватный; публичная карточка ведёт в контакты.

  README и `docs/product-overview-ru.md`. Заявляем назначение, 24 выхода / 24 входа
  и RS-485/Modbus. Проверку прошивки на оборудовании не выполняли; никаких новых
  гарантий безопасности или готовности серийного изделия не добавлено.
