# Platerra: от устройства до облака

Новая версия корпоративного сайта: собственные решения L4Desk, Leo4 IoT Platform,
PlaterraTerminal и экспертиза распределённых приложений. Главная и пять внутренних
страниц собираются в статический HTML без WordPress, npm-зависимостей и клиентского
фреймворка. Оригинальные схемы выполнены в HTML/CSS/SVG.

## Локальный запуск

```powershell
cd D:\work\iot.leo4.ru\platerra.ru\website
npm run build
npm run check
python -m http.server 8770 --bind 127.0.0.1 --directory dist
```

Открыть http://127.0.0.1:8770/. Сборка работает на Node.js 22+.

## Исходники и материалы

- `src/content.mjs`: продуктовые описания, функции, сценарии.
- `src/projects.mjs`: краткие описания 18 проектов и трёх направлений контроллеров.
- `src/templates.mjs`: HTML всех страниц и метаданные.
- `src/styles.css`, `src/main.js`: оформление и небольшие интерактивные элементы.
- `assets/`: локальные изображения и собственный знак, социальное превью.
- `build.mjs`: генератор страниц, robots.txt, sitemap.xml и страницы 404.
- `materials/`: источники утверждений, оригиналы FTP-изображений и карта старых URL.
- `docker/`, `docker-compose.yml`: подготовленная конфигурация статического сервиса.

Контакт, подтверждённый владельцем: **info@platerra.ru**. Телефон сохранён со старого
публичного сайта. Кнопка на странице контактов открывает почтовую программу с темой
и структурой письма. Серверной формы и фиктивного сообщения об отправке нет.

Подборка проектов показывает заголовок, контекст и одно предложение без крупных
изображений. Фильтры переключают направления; полный список доступен без JavaScript.
Экраны PUNTOPAGO загружаются только при раскрытии. Подборка основана на восстановленном
архиве владельца; связи с источниками сохранены в `materials/project-sources.json`.
Контроллеры представлены на главной, странице Leo4 и экспертизы. L4-HMI — развиваемый
проект; его приватный GitHub не используется как публичная ссылка для посетителей.

## Размещение на 176

Подготовлен отдельный контейнер, опубликованный только на `127.0.0.1:8088`,
с лимитом памяти 64 MiB и CPU 0.5. Перед публикацией необходимы проверка свободного
порта, сборка и `nginx -t`, настройка домена/TLS во внешнем reverse proxy и актуальная
проверка ресурсов 176. Новый контейнер не заменяет L4Desk.

**Историческая проверка до размещения.** На этапе подготовки
локальный Docker daemon недоступен. Проверены Node-сборка,
статические файлы и работа в браузере. Локальная Compose-команда также недоступна;\nсборка контейнера и проверка Compose остаются этапом размещения.

До переключения DNS нужно согласовать новый дизайн и закончить карту старых URL.
Инвентаризация выявила 42 адреса основного контента: 8 страниц, 12 проектов,
9 услуг и 13 публикаций. Девять проектов явно относятся к демонстрационному шаблону;
три содержательные публикации требуют отдельного решения о сохранении.
PUNTOPAGO и Trailquipt уже представлены в подборке проектов с подготовленными redirects.
См. `materials/migration.md`. Не направлять все удалённые URL на главную.
Почтовые MX/TXT-записи не менять при переносе веб-сайта.

Сайт размещён на сервере 176 с отдельным контейнером и HTTPS через общий входящий
nginx. Конфигурация публикации находится в `../deploy/`; подробности и результаты
проверок — в `../deploy/deployment-20261009.md`. DNS переключает владелец домена.

Новые фото и кадры из `D:/work/img/`, их отбор, обработка и экспорт описаны
в [materials/media-processing.md](materials/media-processing.md).
Оригиналы и мастера сохранены рядом с исходниками сайта. В подборке проектов
есть 18 отдельных SVG-иллюстраций, кадры оборудования открываются по запросу.

2026-10-09: шесть страниц проверены Playwright на 1440, 768, 390 и 320 px.
Горизонтального переполнения нет. Проверены полноразмерный скриншот, Escape,
восстановление фокуса/прокрутки, мобильное меню, тема письма и навигация без JS.
`npm run build`, синтаксис JavaScript, локальные ссылки/ассеты и `git diff --check`
проходят. Скриншоты для просмотра находятся в игнорируемой папке `.preview/`.

FTP использован только для чтения. Пароли остаются вне репозитория. Старый сайт,
DNS и серверные файлы в этой задаче не изменялись.
